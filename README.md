# Landau-Analysis-of-Six-Point-One-Mass-Feynman-Integrals
This repository presents the Landau singularities calculated for various six-point one-mass Feynman integrals. This work was done for the Bachelor’s thesis in Physics submitted to the Mathematisch-Naturwissenschaftlichen Fakultät der Rheinischen Friedrich-Wilhelms-Universität Bonn.
